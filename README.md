
# PDF Password Auditing

A hands-on cybersecurity project documenting PDF password auditing and password recovery techniques using **John the Ripper (JtR)**, the **RockYou wordlist**, and **Networkwalks security tools**.

This repository covers the practical workflows completed in Week 03 (PM1 & PM2), including:

- PDF password hash extraction.
- Wordlist-based password auditing.
- Password recovery using John the Ripper.
- Hash calculation and password testing using Networkwalks tools.
- Password verification and training flag capture.
- Technical documentation and practical evidence.

**Tools & Technologies:** Kali Linux, John the Ripper, RockYou Wordlist, Networkwalks Hash Calculator, Networkwalks Password Cracker.

**Environment:** Controlled cybersecurity training lab.

**Objective:** Develop practical knowledge of PDF password security, hash extraction, and password auditing methodologies.

**Disclaimer:** All activities were performed on assigned training files in an authorized learning environment. These techniques should only be used on files you own or have explicit permission to test.
